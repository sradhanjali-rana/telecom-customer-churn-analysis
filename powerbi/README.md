# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Telecom Customer Churn Analysis project.

## Dashboards

1. Executive Churn Overview
2. Customer Usage & Recharge Analysis
3. High-Risk Customer Analysis

## Key KPIs

- Total Customers
- Churned Customers
- Churn Rate
- Average ARPU
- Average Recharge Count
- Average Voice Usage
- Average Data Usage

## Tools

Power BI

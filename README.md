# Telecom Customer Churn Analysis

## Project Overview

This project analyzes customer behavior in the telecom industry to understand customer churn and identify factors associated with customer attrition.

## Industry
Telecom

## Function
Operations

## Dataset

The dataset is from the Kaggle Telecom Churn Case Study Hackathon.

It contains:
- Train dataset: 69,999 records and 172 columns
- Test dataset: 30,000 records and 171 columns
- Sample submission file
- Data dictionary

## Problem Statement

Telecom companies may lose customers due to changes in usage, recharge behavior, revenue contribution and service engagement. This project aims to analyze customer behavior and identify patterns associated with churn.

## Business Objectives

- Identify factors associated with customer churn
- Analyze customer usage and recharge behavior
- Identify customer segments with higher churn risk
- Support customer retention strategies
- Help reduce customer attrition

## Analysis

### Descriptive Analysis
- Customer churn distribution
- ARPU analysis
- Recharge behavior
- Voice usage
- Data usage
- Customer tenure

### Diagnostic Analysis
- Churn vs ARPU
- Churn vs tenure
- Churn vs recharge behavior
- Churn vs voice usage
- Churn vs data usage

### Predictive Analysis
A Logistic Regression model was developed as a baseline model to estimate customer churn probability.
